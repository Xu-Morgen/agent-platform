开始使用

配置连接环境，加载并保存服务，然后提交任务查看运行结果。

环境配置管理模型、API 连接和凭据 服务配置加载本地定义，配置预算和管理版本 任务调用提交输入，查询进度、用量和结果

配置保留方式见左侧存储状态。凭据保存后仅显示引用；留空表示保留已有凭据。

测试连接会发送一次小型请求，可能产生模型费用。

API 连接供通用块节点选择；请求路径在节点中配置，请求方法、参数和响应契约由块定义。凭据按 Bearer Token 发送。
