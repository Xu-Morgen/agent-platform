# 数组遍历与枚举分支实施计划

日期：2026-09-21。状态：C1–C6 已完成并归档。当前使用入口为[控制流手册](../../control-flow.md)。本文件保留原始需求及分阶段验收记录。

## 1. 目标与现有基础

用户要求另立数组循环，显式选择数组并按其实际长度执行；增加单选多出口的枚举分支。保留现有 if、repeat、while；不引入多 Agent、断点续跑、并行分支或模型生成流程。

实施前 `flow-5` 的权威定义在 [flows.py](../../../src/agent_platform/contracts/flows.py)，[保存校验](../../../src/agent_platform/flows/validation.py)与[执行器](../../../src/agent_platform/flows/execution.py)均要求 if/while 条件为严格 bool。repeat/while 通过 carry 更新整体状态。新增能力需要同步协议、校验、编译、快照与编辑器，不能只修改次数计算或放宽 bool 校验。

关联：[文档管理与最小 RAG](knowledge-rag-plan.md)、[黑神话业务实验](../../black-myth-rag-experiment-plan.md)。先交付控制流，再用业务实验检验新节点；文档管理的数据设计可独立推进。

## 2. 数组遍历 foreach

### 2.1 配置与数据语义

- 增加独立 `foreach` 容器；配置完整数据来源、数组字段路径、最大条数、元素输出契约和循环体。名称为设计用语，正式字段由权威模型统一确定。
- 来源仅允许服务输入或当前作用域内已经执行的合法来源，包括合法的外层循环数据；不允许前向、跨分支、跨服务或其他轮次引用。
- 页面根据来源 Schema 列出数组字段。首版支持确定对象字段路径与根数组；不支持任意表达式、通配符、数组下标、条件筛选及动态字段名。可空或结构不确定的来源先经通用块规范化。
- 数组定位是控制容器的有限能力，不把业务字段选择、改名、合并开放给普通节点。
- 进入容器时固定本次数组，执行次数等于数组长度；超过 `maxItems` 在执行第一项前报错，不截断。空数组执行零次。
- 每轮首节点 `primary` 为当前元素，默认零参考；完整请求、知识库快照等上下文通过作用域内完整来源显式配置 references。首版不增加可跨轮次更新的 foreach carry，也不隐式注入索引到业务元素。
- 每轮从独立作用域开始，顺序执行，输出为循环体最后一步完整输出；元素输出契约明确且每轮校验，首版不允许空循环体。
- 容器输出采用固定集合封装 `items: list[元素输出契约]`，保持输入顺序；集合契约从元素契约推导，避免手写两份类型。容器之后的默认参考为进入容器的完整主数据，不是最后一项。
- 空数组产生 `items: []`；下游如要求非空应由保存校验或实际入口校验明确拒绝，不能伪造一项。

### 2.2 执行边界

共用任务预算、取消与图步数检查；每次模型调用尝试仍计 loop，元素个数不直接等于模型调用数。首版任一项失败即任务失败，不返回伪装成功的部分结果；历史步骤保留已经执行的记录。

契约重试仅限现有规则允许的生产节点，不能因集合输出失败而整体重跑所有元素，也不能重跑无关历史来源。每轮记录包含容器 ID 和元素索引，便于定位；嵌套容器遵守相同作用域规则。

## 3. 枚举分支 switch

- 新增 `switch`；if/while 继续接收严格 bool，不把旧 if 静默改造成新协议。
- 路由节点是 Python 通用块，通过 NodeInput 接收主数据与参考，返回有限字符串 `Literal`/等价字符串枚举；拒绝任意字符串、数字、隐式转换和模型直接生成分支配置。
- 配置者为每个枚举值配置一个分支，首版要求完整覆盖、值不重复、不包含声明外的值；不提供隐式 default。
- 一次执行路由块，只选择一个分支。路由结果不替换业务主数据，分支入口延续容器入口的数据与参考语义。
- 所有分支出口满足统一声明的输出契约；不同业务结果可通过显式汇总块转换为共同结构。若使用联合契约，必须先验证当前兼容检查器对该结构的支持，不能仅凭类型标注放行。
- 路由结果非法时明确失败。选中分支外的节点不执行；分支内部结果不泄露到其他分支或外层，外层只使用容器完整输出。
- 复用现有分支空体与完整来源绑定能力时，须逐项验证；不新增字段映射。

示例路由值：`pass / revise / regenerate / insufficient_source`。模型可输出审题业务结论，Python 块依据已声明数据返回路由枚举；路线、代码及分支均由配置者预定义。

## 5. 轻量验收清单

- [x] foreach：0/1/多项、顺序、最大条数超限、字段不存在、字段不是数组、元素与循环体入口不兼容。
- [x] foreach：嵌套对象数组选择、根数组、跨轮次残留隔离、外层合法参考、内层结果越域拒绝、集合输出兼容。
- [x] switch：覆盖全部出口、缺失/重复/额外枚举值、路由返回非法值、未选分支无副作用、分支出口不兼容。
- [x] 组合：foreach 内含 switch，switch 内含循环，与现有 if/while/repeat 及一层固定服务组合互操作。
- [x] 生命周期：节点重试不重放容器，预算耗尽、运行取消、关闭应用及重启后中断记录符合当前语义。
- [x] 页面与持久化：正式页面保存、重启加载、历史只读边界、实例版本和引用固定正确。

不为本计划安装依赖、运行重型测试或自动打包。实施阶段按实际需要执行轻量验证；完成后删除临时测试、脚本、数据和缓存，保留使用说明与交付资源。本计划对应功能现已完成；原始验收范围与实际结果见下列实施记录。


## 6. 实施记录

### C1 协议定稿（2026-09-21）

- 新执行协议定为 `flow-6`；协议切换及旧实例只读提示在 C4 验证。
- `foreach` 字段：`source`（完整 PortReference）、`arrayPath`（对象字段名数组，空数组表示根数组）、`maxItems`（正整数）、`itemOutputContract`、非空 `body`。集合固定为 `{items: [...]}`，Schema 从元素出口派生。
- 新增 `item` 完整来源，`nodeId` 指向可见外层 foreach 当前元素；与 `carry` 分开，不允许更新。普通节点仍不提供字段映射。
- `switch` 字段：Python 块 `router`、`outputContract`、`cases`；每个 case 包含字符串 `value`、`nodes` 和完整来源 `output`。结构层拒绝重复值、非块路由；枚举覆盖由 C2 校验。
- `walk_nodes` 统一遍历路由块、每个枚举分支及数组体，所有嵌套节点继续使用全局唯一 nodeId。
- 轻量验证：模型导入及 Schema 生成通过；合法 foreach/switch、空数组路径与 item 来源解析通过；空 body、重复 case、非块路由、非法最大条数及重复 nodeId 拒绝通过。

### C2 静态校验（2026-09-21）

- 数组路径只经过确定、必填的对象字段，保留元素 Schema 的引用定义；集合出口从元素契约派生。
- foreach 当前元素与 carry 分开建模，检查合法外层参考、逐轮独立作用域及元素出口；来源、路径、元素出口错误分别定位 `source`、`arrayPath`、`itemOutputContract`。
- switch 校验 Python 路由入口、有限字符串枚举、完整覆盖及每个分支出口；路由和分支问题分别定位 `router`、`cases`。
- 轻量断言通过：根数组、嵌套对象数组、完整服务参考、当前元素参考、foreach 后默认参考、foreach 内 switch；拒绝可空数组、字段不存在、数组下标路径、非空集合要求、元素契约不兼容、前向来源、内层结果越域、任意字符串/数字路由、缺少/额外出口与跨分支引用。
- 节点遍历已由 C1 统一扩展；快照资源收集在 C4 验收。

### C3 执行器（2026-09-21）

- foreach 进入时复制选中数组，先检查 maxItems，再按顺序执行；每项从容器外状态深复制独立作用域，当前元素不更新 carry；逐项校验后生成有序 items。
- switch 独立执行路由块，仅运行选中分支，路由结果不替换业务数据；if/while 严格 bool 不变。
- 下游 switch 路由入口纳入直接生产节点预校验。foreach 元素末节点按元素出口重试，元素出口检查不触发外层服务的终态回调。容器出口失败不重放容器。
- 轻量执行断言通过：0/1/多项、顺序、首项前超限、非法路由重试耗尽、未选分支零执行、元素局部重试（前后已成功项各执行一次）、嵌套 foreach、switch 内 if/repeat/while、foreach 内固定叶子服务、容器后入口错误不重放元素。
- 使用既有边界策略注入验证取消、loop/token 预算及应用退出终止；图步数上限验证通过。执行路径含 foreach 容器 ID 和元素索引。此为离线执行断言，不代表真实模型或桌面生命周期验收；桌面及持久化继续在 C4–C6 验证。
