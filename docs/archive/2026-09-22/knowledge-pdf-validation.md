# 知识库 PDF 支持验收记录（2026-09-22）

历史记录；当前资源与准备方式见 [RAG 手册](../../../resources/rag/README.md#pdfocr-资源与升级)。

用户需求：当前知识库上传及业务出题支持 PDF。

交付：知识库 PDF/DOCX 上传、跨格式替换、原格式历史与副本、正确 MIME 和桌面保存后缀；默认读取块 2.0.0 支持 PDF 文字层及扫描/混合页 OCR、真实页码与规范化字符定位；中间文档元数据相关的列举、预览、检索、证据整理资源同步升为 2.0.0。业务出题继续使用 EvidenceContext，不改模型 Prompt 和执行协议。

轻量验证通过：

- 合成两页 PDF 上传、元数据、证据摘要与页码、词面检索和证据登记；DOCX 读取回归。
- PDF 替换为 DOCX、历史两种格式及旧修订原件；重新构造仓储仍能解析元数据。此项使用内存仓储，不是 PostgreSQL 重启验收。
- 实际块子进程执行，受控任务原件副本后缀为 .pdf，输出经过严格契约校验。
- 真实合成扫描页通过本机已有 RapidOCR 模型识别；需要打开密码、损坏 PDF 和 101 页文档明确报错；片段上限标记范围受限，伪造扩展名拒绝上传。
- 全部默认 RAG 块与短语检索块加载，列举/预览准备→读取→三种检索→证据整理的严格静态接线通过。
- 隔离 Electron + 内存后端：实际文件选择器上传 PDF、列表显示、替换选择器支持 PDF、下载内容与原件逐字节相同、另存为默认后缀为 .pdf。保存对话框在验证中定向到临时文件，未覆盖用户文件。
- JavaScript 语法及 Git 差异检查通过。

未安装依赖或模型，复用本机已有环境；未运行构建或调用真实出题模型。测试脚本、合成数据及 Electron 临时目录交付时清理。正式 7.0 服务与预览实例的固定快照未自动升级，须按当前资源手册通过页面加载新版相关块、替换节点和保存新实例；PDF 真实模型出题、复杂排版 OCR 质量与 PostgreSQL 重启尚未在本轮验收。历史 DOCX 内容质量结论不扩展至 PDF。

当前入口：[知识库](../../knowledge.md)、[资源升级步骤](../../../resources/rag/README.md#pdfocr-资源与升级)。
