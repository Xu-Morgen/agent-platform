# 固定版本服务嵌套与选择器改进

日期：2026-09-20。已完成并归档；当前操作入口为[服务组合使用说明](../../service-composition.md)。

## 已确认目标

- 服务可作为拼图节点，绑定已保存的固定实例；更新子服务不改变父实例。
- 改善服务页资源选择：搜索与业务包、通用块、契约分类 Tab，补充服务入口。
- 契约按可证明相同的内容合并选择项，展示结构、约束和全部来源，保留历史引用。

## 实施边界

- 首次交付一层服务嵌套；不允许服务自引用或引用已含服务节点的实例。
- 子服务接收上一层完整业务数据，不接收或访问父流程 references；返回固定业务输出。
- 子流程使用同一任务、取消、环境占用及实际调用记账。内部节点使用服务节点路径区分；子服务预算在父任务内按该服务节点累计，父任务总预算同时生效。
- 保留内部节点的契约重试，不因子流程或下游失败整体重跑子服务。
- 不修改既有实例；新增节点是 flow-5 的向后兼容结构扩展，已有 flow-5 快照摘要保持不变。
- 契约以结构约束去重；含运行时自定义校验者只合并同一身份。不会用 JSON Schema 相同替换不同 Python 校验。

## 实际交付与验证记录

- 服务节点固定叶子实例，保存、版本更新、回退及 JSON 仓储恢复保持引用；禁止自引用、多层引用和不兼容接线。父身份纳入子快照摘要，既有 flow-5 摘要不因新增节点类型被重写。
- 共享父任务的环境固定/占用、取消、图步数与用量。内部节点标识包含所属服务路径；重复引用分别记账，同一引用在循环中的子服务预算累计执行。
- 末尾生产者输出不符合父流程直接下游主输入时，仅重试末尾节点；通过实际 Python 块与离线模型适配器检查前置块只执行一次、下游校验通过前不执行。子服务失败不会整体重放。
- 契约共享身份同时比较规范化结构、默认值、别名与 Pydantic 校验配置；保留自定义/不可比较校验身份。旧 SDK 未提供校验描述的块保持独立，不猜测相等。
- 实际 Electron + 独立内存后端：加载最小包/块/契约，五个相同契约来源归并为一个选择项；搜索、来源 Tab、插入 Tab、服务版本节点、页面保存叶子与父服务、实际纯块任务完成、历史节点名称均通过；960/600 像素页面无横向溢出，契约弹窗已截图检查。
- 恢复检查对仓储记录进行 JSON 往返并打乱实例顺序，验证子服务升级不影响父实例。删除临时原始块源码后，仍从持久源码记录重建并实际运行嵌套块。
- 离线模型协议检查通过内部重试、次数累计、父 loop/token 超限、子服务累计上限、同名内部节点隔离、环境占用及取消边界；这些结果不代表真实模型验收。
- Python 导入/编译、相关 JavaScript 语法、两个新增只读接口响应契约、Git 差异与文档链接检查完成。

## 未实现及验证限制

- 本轮未调用外部模型，未重复 PostgreSQL 桌面重启生命周期验收；仓储恢复检查不能替代该集成验收。
- 首版仅一层嵌套，不开放子服务参数覆盖、跨服务 references、自动升级引用、动态选择服务或任务续跑。
- RAG 通用服务与评价组合服务尚未制作。本任务交付其可复用的固定版本服务组合基础。
- 临时验证脚本、合成数据与运行缓存已清理，不保留为回归测试或自动组装业务服务的脚本。
