# Agent Platform

面向业务系统的通用 Agent 服务平台。将 Agent 包挂载到中心，在平台上配置 API、流程和模型环境，形成可被业务系统调用的服务实例。

本仓库以**服务平台**为主项目。Agent 包是遵循平台协议的附属项目，统一放在根目录 `samples/` 下；首期必须交付服务平台产品和业务包产品，业务包产品包含标准模板与最小文本查重包。

## 核心概念

| 概念 | 定义 |
| --- | --- |
| 服务包 | 业务实现及契约，声明输入输出、所需能力和配置项 |
| 服务配置 | 当前环境中的 API、流程、模型绑定及运行参数 |
| 服务实例 | 一个固定包版本与一份固定配置版本组合成的可调用服务 |
| 服务平台／中心 | 负责包挂载、配置、校验、运行和对外调用，并提供共享基础环境 |

```text
服务包声明依赖
    → 平台配置 API／流程／模型绑定
    → 校验并保存，生成立即生效的新实例
    → LMS 等业务系统通过统一接口调用
```

同一服务包可以在多个业务环境中复用。包面向能力契约编写；具体接口地址、认证方式、字段映射和模型凭据由平台管理。必要时，一个依赖可以绑定为调用多个 API 的接入流程。

## 平台与包的边界

- 平台提供通用的配置管理、契约校验、工具执行、模型调用、任务状态和运行记录。
- 包定义业务工具、业务流程、Prompt、结果结构及必要的环境能力。
- 确定性 Python 通用流程块负责固定格式解包、数据清洗与验证；需要语义判断的字段识别由模型完成，包组织业务流程。
- 工具分为数据工具、实施工具和逻辑工具；输入输出均需要运行时校验，编译期类型不能替代校验。
- 后续扩展数据库连接配置与能力绑定；平台运行状态存储和包访问业务数据库是两个独立概念。

## 首期范围

首期交付两个产品：

- 服务平台：服务配置页、环境配置页、包挂载、Python 通用流程块、配置版本与实例历史、任务提交和报告查询。
- 业务包：标准模板、平台接入契约与样例，以及简单文本查重包。输入一份纯文本和对照文本数组，输出定量重复文本相似度报告与定性语义分析报告。

配置更新生成新版本和新实例，成功保存后立即生效；包变更为大版本更新，配置为小版本更新，两者同时变更视为破坏性整体更新。历史回退和运行数据首期仅保留在应用缓存中，重启后不恢复。

首期以一篇约 1500 字文章和另外六篇约 1500 字文章比较作为功能验证样例。主要验收平台闭环和严格输入输出校验，不验证 LLM 判断准确性；是否抄袭由教师综合两类报告自行决定。

权限服务、数据库持久化及直连、性能优化、复杂防御与兜底、完整 LMS 集成及详细查重业务规则后置。首期不实现去重键，每次成功提交创建新任务。旧实例调用与回退细节、取消异常优先级及定量算法口径仍待决定，详见需求文档第 9 节。
