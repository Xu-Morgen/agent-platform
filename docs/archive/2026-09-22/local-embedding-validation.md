# 本地 embedding 验收记录

日期：2026-09-22。此为历史验收记录；当前使用入口见 [本地 embedding](../../local-embedding.md)。按用户后续授权下载模型并安装依赖；没有远端 LLM 调用，不消耗 ds 授权。没有修改现有正式出题服务。

## 制品与运行

- BAAI BGE-small-zh-v1.5 的 Xenova ONNX 转换，固定修订 `75c43b069aac4d136ba6bc1122f995fedcfd2781`。完整适配清单、SHA-256 与运行依赖见 [制品目录](../../../resources/embedding/README.md)。采用 float32 CLS + L2，查询前缀固定，CPU 执行。
- i7-14700 虚拟化环境、Linux x86-64、Python 3.12.3；冷加载 0.55～0.61 秒；1×30 字符 5.1 ms、8×100 字符 80 ms、8×510 字符 515 ms；本轮峰值 RSS 407 MiB。单个模型进程、批次 8、线程 2。这是轻量测量，不是多设备性能结论。
- 缺少清单、缺文件、摘要损坏、超长输入、重复片段、非有限阈值会拒绝。真实模型输出 512 维且有限；单独注入错误验证维度、非有限与零范数拒绝；部分批次注入失败只保留完整成功的 8 条，直接引擎重试命中 8 条并新增 1 条。注入测试不代替真实模型质量验证。

## 页面与持久化

在独立临时 Electron/PostgreSQL 数据目录验证，使用正式页面控件：模型导入、保存默认选择、小样例诊断；源目录移走后应用副本仍能编码，模型选择跨停库重启保留。通过服务拼图加载五个正式 RAG 块，配置高级参考为空，分别保存两个独立 1.0 服务：

- 本地语义检索验证：列举文档 → DOCX 读取 → 本地语义检索 → 证据登记。
- 词面对照验证：仅将检索步换为原词面块，其余相同。

两者输入 `RetrievalRequest`、输出 `EvidenceContext`；无需 Prompt 包或模型连接。页面输入同一份合成 DOCX，6 段分别涉及电脑无法开机、运行缓慢、紫霄山天枢阁开放时间、重置密码、雨天防护、电池老化。

## 实际相关片段检查

每次 topK=3，语义搜索不设最低分；词面维持现有规则。下表人工核对问题、完整候选正文和段落定位，相关性仅针对合成资料。

| 类别 / 查询 | 语义 top1 与分数 | 词面结果 | 结论 |
| --- | --- | --- | --- |
| 同义改写：机器按下开关后毫无反应，该排查哪里？ | 无法开机/检查电源，0.5663 | 无候选 | 本例语义补充了词面召回 |
| 专名：紫霄山天枢阁星期一能参观吗？ | 开放时间/周一闭馆，0.6927 | 同一段为 top1 | 两者命中 |

八个实际服务任务均 completed；每个语义任务新编码 6 条、缓存命中 0、2 个批次，文档 202 token，查询 33～41 token；推理约 30～44 ms。记录包含模型、候选、定位、范围、源码与统计，登记证据可追到固定 DOCX 原件。语义分数和词面分数不可混加。本轮没有调用回答包或评价生成质量；没有测大规模召回率，不宣称总体优于词面。

## 生命周期与范围

- 同任务重复检索命中 2 条缓存；另一任务从 0 命中开始；清空默认选择不影响已经固定模型的任务。
- 零片段返回空；显式 minimumScore=1 的不相同文本返回空；相同分数保持输入顺序。
- 1200 字正文按 tokenizer 切分可原样拼接，字符偏移可追溯；超片段上限明确失败，不裁剪范围。
- 伪造文档 ID 被拒绝；更新知识库后旧任务仍能检索旧版本，新版本越入旧任务范围被拒绝。恢复未结束记录保留模型快照并标记 APPLICATION_INTERRUPTED，不恢复执行。
- 容量等待中的任务取消后不加载模型；真实服务在本地推理中取消为 cancelled/RUN_CANCELLED。真实页面推理中关闭应用，重启后保留 APPLICATION_EXIT；没有孤立块或模型进程。
- PostgreSQL 重启后实际 completed 任务的候选、证据、模型和统计恢复；历史页面展示通过。检查持久记录未包含向量数组。

原样例、临时脚本、临时桌面配置与验证数据库在交付清理时删除，不保留自动服务组装脚本。模型源制品作为经授权下载的可导入资产保留在本机缓存目录，仓库仅保留清单和手册。
